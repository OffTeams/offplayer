# OFFPlayer

Офлайн-плеер для Android в стиле YouTube Music. Музыка и видео — в разных вкладках нижнего меню.

## Возможности
- **Музыка**: треки, альбомы, исполнители, плейлисты; сортировка; «Воспроизвести далее» / «В очередь».
- **Плейлисты**: создание, переименование, перетаскивание треков, автосортировка, кнопка «По кругу» (бесконечный повтор).
- **Плеер**: анимированная виниловая пластинка с обложкой и тонармом, повтор (выкл / очередь / трек), перемешивание, редактируемая очередь, таймер сна, фоновое воспроизведение с уведомлением.
- **Видео**: папки, сортировка, плеер с «картинкой в картинке» (кнопкой или автоматически по «Домой») и фоновым звуком.
- **Загрузки**: ссылка с YouTube / YouTube Music (или «Поделиться» из приложения YouTube) → MP3/M4A/Opus с обложкой и тегами или MP4 нужного качества. Работает через yt-dlp + ffmpeg (youtubedl-android); кнопка «Обновить yt-dlp».

## Сборка
Нужны JDK 17 и Android SDK (путь задаётся в `local.properties`).

```
gradlew assembleDebug
```

Подписанный релиз:

```
gradlew assembleRelease
```

APK появляются в `app/build/outputs/apk/release/` с именами вида `OFFPlayer-1.1.0-arm64-v8a.apk`: для современных телефонов подходит `arm64-v8a`, а `universal` работает на любом устройстве.

## Подпись
Релиз подписывается ключом `keystore/offplayer-release.jks`, пароли хранятся в `keystore.properties`. Сделайте резервную копию обоих файлов: без них не получится выпустить обновление, которое установится поверх текущей версии. При каждом выпуске увеличивайте `versionCode` в `app/build.gradle.kts`.
